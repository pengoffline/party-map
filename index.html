Party Values Map

根據世界價值觀調查，找出你的政治定位，比較你和各國不同政黨支持者的差異

本測驗題目源自跨國研究「世界價值觀調查」（World Values Survey）第七波問卷（2017-2022年施測）中與政治相關的題目，共有26題，作答時間約10分，分為三個面向和一個綜合分數，以1-10分衡量。

  • 經濟（市場⭤平等）：得分接近1表示傾向自由放任與個人競爭的價值觀，接近10則較支持政府介入以提升平等
  • 政治體制（威權⭤民主）：得分接近1表示支持強人統治、政府監控，接近10則重視民主和限縮政府權利
  • 個人選擇（傳統⭤進步）：得分接近1表示對於性與生命持有保守的看法，接近10則較為開放、更強調自主權利
  • 社會：政治體制與個人選擇的平均值，代表政治與文化上的總體自由度

測驗完成後，我們會透過得分分析你的政治傾向，並使用WVS對各國的調查結果，計算出你與哪一個主要政黨的支持者群體擁有最相近的看法，國家涵蓋台、港、馬、美、日等共12區域。並且有兩張分布圖讓你自行比較和不同政黨、國家、其他填答者的差異。
